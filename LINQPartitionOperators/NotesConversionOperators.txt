AsEnumerable: converts it to IEnumerable
IEnumerable<T> represents a collection of data that can be iterated in the memory. Simply understand it as : IEnumerable works on the data already loaded in the memory of the app.
All LINQ queries are executed in the memory AND NOT IN DATABASE.



Use IEnumerable:
In memory data, Complex C# logic and small collections

AsQueryable: converts it to IQueryable
IQueryable<T> represents a query that is not executed immediately but instead 
translated and executed by and external datasource (like database)
IQueryable builds query---->sends it to db---->db will execute it.
It will be used when LINQ queries are executed outsude the application, typically in the database.

for eg:
IQueryable<Employee> query=db.Employees.Where(e=>e.Age>30);
foreach---then output
IQueryable: use when:
Large Data and DataBase Filtering, sorting and paging is required.
